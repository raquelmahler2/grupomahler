# Grupo Mähler

Site institucional do Grupo Mähler — Editora Mähler, Consultoria Mähler e Keké Art Gallery.

Página estática (HTML + CSS), publicada pelo GitHub Pages em https://grupomahler.com.br.

- `index.html` — conteúdo da página
- `assets/style.css` — estilos (paleta preto, marrom, creme e dourado; fontes Cormorant Garamond e Pinyon Script)
- `assets/*.svg` — monograma do grupo e emblemas de cada empresa (traço fino, estilo pena)
